3. Local Code Execution

Where Dart code execution is performed locally on the user's device, the source code and execution process may remain on the device and does not need to be transmitted to our servers solely for execution.

Local execution may require temporary files, application storage, runtime components, or other technical resources on the device.

4. Online or Server-Based Code Execution

If a compiler or code execution feature sends Dart source code to a remote server or third-party service for processing, the submitted code and associated technical information may be transmitted over the internet.

Such processing is performed where required to provide the relevant compiler or execution functionality.

Security Recommendation: Users should not enter passwords, API keys, private credentials, financial information, confidential company information, or other sensitive information into source code submitted for online execution.

Dart & Compiler may allow users to save Dart programs and related content locally on their device.

Locally saved files are controlled by the user and may remain on the device until the user deletes them or removes the application, subject to the behavior of the Android operating system.
